## 🚇 Kluczowa logistyka w skrócie

### Genua
- **Lotnisko Genua → Galea Studio**: Volabus do Principe lub taxi; nocleg leży blisko historycznego centrum i Porto Antico
- **Galea Studio → akwarium / Porto Antico**: spacer ok. 10-15 minut
- **Galea Studio → Genova Piazza Principe**: spacer ok. 10 minut, wygodnie pod pociąg do Santa Margherita Ligure na Portofino
- **Galea Studio → przystanek FlixBus / stacja**: najlepiej zamówić taxi na bardzo wczesny wyjazd 24 maja

### Londyn
- **Luton → easyHotel Old Street**: DART/shuttle do Luton Airport Parkway, pociąg do St Pancras, dalej Northern Line do Old Street lub taxi z King's Cross/St Pancras
- **easyHotel Old Street → strefa kibiców Arsenalu**: Northern Line do King's Cross, dalej Piccadilly Line do Arsenal albo bezpośrednio taxi do Highbury / Holloway Road
- **easyHotel Old Street → City / Tower / Borough**: szybkie połączenia metrem lub 20-35 minut spacerem
- **easyHotel Old Street → Stansted**: Overground / metro do Liverpool Street, dalej Stansted Express
